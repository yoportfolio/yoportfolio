YURI OTA PORTFOLIO — GitHub Pages公開用

1. ZIPを解凍します。
2. portfolioフォルダの中身（index.html、style.css、script.js、assets、usagi、.nojekyll）を、yoportfolioリポジトリの公開元に配置します。portfolioフォルダ自体ではなく中身を配置してください。
3. GitHubのSettings → Pagesで、公開元のブランチ・フォルダを設定します。
4. 公開後のURL： https://yoportfolio.github.io/yoportfolio/
   Web作品： https://yoportfolio.github.io/yoportfolio/usagi/

ローカル確認はindex.htmlをブラウザで開きます。画像や動画は同梱フォルダを参照するので、HTMLだけを移動しないでください。
PC：矢印ボタン／左右キー。目次・一覧から直接移動。拡大から詳細確認。
モバイル：縦スクロール。ページ画像のタップまたは拡大ボタンから拡大。
3秒のキャラクター動画は音なしループ再生、クリックで一時停止。20ページの動画は再生ボタンで再生します。自動再生が制限された場合は動画をクリックしてください。
